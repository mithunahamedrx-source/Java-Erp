# Trioloo ERP Final Design Reference

This folder contains the single approved final design reference for the ERP prototype.

- Use `Trioloo ERP Final Design Reference.dc.html` as the current design source.
- Use the local `support.js` beside it when previewing the prototype.
- Older screenshots, invoice mockups, feature-pack HTML files, and order-module prototypes have been removed.
- Reading notes for the design file (module map, Orders card anatomy, known differences from canon): `FINAL_DESIGN_REFERENCE_NOTES.md` — a working record, not canonical.
